🧬 بهینه‌سازی استراتژی با هوش مصنوعیAI Strategy Optimizer

استراتژی را انتخاب کن، دکمه «بهینه‌سازی» را بزن: بکتست تازه اجرا میشود، نتایج برای AI ارسال و نسخه بهبودیافته به‌عنوان یک شاخه جدید ذخیره میشود — استراتژی اصلی دستنخورده میماند. سپس شاخه جدید خودکار بکتست میشود؛ اگر بهتر نشد، AI توصیف استراتژی (vibe) را دوباره تفسیر و شاخه دوم میسازد. اگر vibe ذخیره‌شده نداشته باشد، خودکار از استراتژی موجود تولید میشود. برای Legacy: قفل است اما AI میتواند از رفتار آن شاخه خارجی جدید بسازد.Pick a strategy and press "Optimize": a fresh backtest runs, results go to the AI, and an improved version is saved as a NEW branch — the original stays untouched. The branch is then auto-backtested; if it did not improve, the AI re-interprets the strategy description from scratch and builds a second branch. If no description exists, one is auto-generated from the strategy. Legacy is locked but the AI can derive external branches from its behavior.

🚀 تفاوت «شروع موتور» و «اسکن فوری»
  • شروع موتور: خودکار — هر بار کندل ۱۵ دقیقه بسته شود (با ۱۰ ثانیه تأخیر)، همه نمادها اسکن، پوزیشنها مدیریت و معامله جدید باز میشود. تا وقتی «توقف موتور» نزده باشید ادامه میدهد.
  • اسکن فوری: دستی — فقط یک دور همان کار را همین حالا انجام میدهد. برای تست سریع تنظیمات یا دیدن فرصتها بدون منتظرماندن برای کندل بعدی.
  • هر دو فقط روی کندل بستهشده تصمیم میگیرند (بدون Look-ahead).
⚙️ قبل از شروع چه چیزهایی را تنظیم کنید؟
  1. حالت پیپر (تب تنظیمات): اسپات (فقط خرید) یا مارجین (خرید+فروش با اهرم، لیکوئید و بهره). تغییر حالت حساب را ریست میکند.
  2. موجودی پیپر: پیشفرض ۱۰٬۰۰۰ USDT — قابل افزایش/کاهش/ریست.
  3. نمادها: لیست نمادهای USDT/TMN را انتخاب کنید. هرچه بیشتر، اسکن طولانیتر (۱۲ ثانیه فاصله بین هر درخواست API والکس).
  4. بکتست: قبل از اعتماد به استراتژی، تاریخچه دانلود و بکتست/Walk-Forward بگیرید؛ PF و WR را با Paper زنده مقایسه کنید.
  5. معامله واقعی (اختیاری): کلید API + متغیر محیطی WALLEX_LIVE_ALLOWED=yes + تأیید صریح. پیشفرض هیچ کلیدی لازم نیست.
📊 استراتژی در یک نگاه
  • سیستم اسکن خودکار هر نماد را در تایم‌فریم‌های مختلف بررسی کرده و فرصت‌های معاملاتی را بر اساس معیارهای تعریف‌شده شناسایی می‌کند.
  • هر فرصت شامل نقاط ورود، هدف سود، حد ضرر و امتیاز کیفیت است.
  • مدیریت ریسک در هر معامله اعمال می‌شود و پوزیشن‌های باز در صورت رسیدن به TP/SL یا شرایط لیکویید خودکار مدیریت می‌شود.
  • در حالت مارجین، بهره و لیکویید طبق قوانین صرافی محاسبه و اعمال می‌شود.
⚠️ هشدارهای مهم
  • Drawdown ≥ ۱۲٪ ورود جدید را متوقف میکند — از دکمه ریست Drawdown (در آمار عملکرد وقتی فعال شود) استفاده کنید.
  • در حالت مارجین، بهره هر ۴ ساعت از سود کسر میشود — پوزیشنهای طولانیمدت حتی بدون حرکت قیمت ضرر میدهند.
  • فاصله ۱۲ ثانیه بین درخواستها یعنی اسکن ۲۰ نماد ~۸۰ ثانیه طول میکشد.
  • این ربات هیچ سودی تضمین نمیکند.
🚀 "Start Engine" vs "Quick Scan"
  • Start Engine: automatic — every time a 15m candle closes (10s delay), all symbols are scanned, positions managed, new trades opened. Continues until you press "Stop Engine".
  • Quick Scan: manual — runs one pass right now. Good for quick tests or seeing opportunities without waiting for the next candle.
  • Both decide only on closed candles (no look-ahead).
⚙️ What to set up before starting?
  1. Paper mode (Settings tab): spot (long-only) or margin (long+short with leverage, liquidation, interest). Changing mode resets the account.
  2. Paper balance: default 10,000 USDT — add/remove/reset freely.
  3. Symbols: pick your USDT/TMN symbol list. More symbols = longer scans (12s gap between Wallex API calls).
  4. Backtest: before trusting a strategy, download history and run backtest/Walk-Forward; compare PF and WR against live Paper.
  5. Live trading (optional): API key + env var WALLEX_LIVE_ALLOWED=yes + explicit confirmation. No key needed by default.
📊 Strategy at a glance
  • The scanner checks every symbol across timeframes and detects setups matching the defined criteria.
  • Each opportunity includes entry, target, stop and a quality score.
  • Risk management applies per trade; open positions are managed automatically on TP/SL or liquidation conditions.
  • In margin mode, interest and liquidation follow the exchange rules.
⚠️ Important warnings
  • Drawdown ≥ 12% blocks new entries — use the Drawdown reset button (in Performance Stats when active).
  • In margin mode, interest is charged every 4 hours — long-held positions lose money even if price stands still.
  • 12s between requests means scanning 20 symbols takes ~80 seconds.
  • This bot guarantees no profit.
